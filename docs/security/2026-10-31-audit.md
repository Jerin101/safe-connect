# Security audit, 31 Oct 2026

Read-only audit of the SafeConnect site, Firestore rules, GitHub Actions, dependencies and Google Cloud / Firebase settings,
followed by one fix per finding (each with its own issue, `/security-review` and tester GO). **All findings are closed.**

## Scope

| Area | What was checked |
|---|---|
| Site code (`js/`, `preview.html`, `reset.html`) | `innerHTML` / `eval` / `document.write`, how data reaches the page, links that open new tabs, the service worker, the password-reset page |
| `firestore.rules` | who can read and write each collection, role changes, audit log, report spam |
| Secrets | full Git history (277 commits) for API keys, private keys, service-account files; `.gitignore` |
| GitHub Actions | permissions, triggers, how actions are pinned, text from government pages in issues |
| Dependencies | `npm audit` of the developer tools |
| Google Cloud / Firebase | web API key restrictions, sign-in settings, service-account keys |

## What was already fine

- No `innerHTML`, `eval` or `document.write` in the site; data is always written with `textContent`.
- Source links can only be `https://…gov.bd` or `acc.org.bd` (checked by `tools/validate_data.py`), so a data file cannot inject a `javascript:` link.
- Every link that opens a new tab uses `rel="noopener"`.
- The service worker caches only same-site GET requests.
- The reset page removes the one-time code from the address bar, sends no referrer, and follows "continue" links only to our own site.
- Firestore rules: admins can only be added in the Firebase console; every admin change needs an audit entry in the same batch; the audit log is append-only; family numbers and saved areas are owner-only; everything not listed is closed.
- Secret scanning: gitleaks scans the whole history on every pull request, and its download is checked against the published checksum.
- The Python data tools keep certificate checking on.

## Known limits

- Someone can create a new account to get a fresh report limit; email verification slows this down.
- The report limit uses the UTC day; a phone with a wrong clock around 06:00 Bangladesh time may see a general error once.
- The note check does not catch a number split by a tab or line break, or a 10-digit number written without the leading 0.
- A `<meta>` CSP cannot stop other sites from framing the page (`frame-ancestors` needs an HTTP header).
