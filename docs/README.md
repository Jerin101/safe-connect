# Documents: what is where

| File or folder | What it is for |
|---|---|
| `PROJECT_BRIEF.md` | Current state of the project in one page |
| `PROJECT_PLAN.md`, `ISSUES.md` | The plan and the issue list (planning IDs `Pxx`) |
| `PLAN_STATUS.md` | Status against the teacher's plan, release scope, test record |
| `FEATURES.md` | Feature list |
| `BUILD_PLAN.md` | Technology, data pipeline, offline list, fallback chain |
| `SYSTEM_DESIGN.md` | How the parts fit together |
| `ROLES.md` | Accounts and roles |
| `DESIGN.md` | Design guide (colours, buttons, text) |
| `FIREBASE_SETUP.md` | Firebase setup, step by step |
| `DATA_GAPS.md`, `DATA_REPORT.md`, `COVERAGE.md`, `SOURCE_CONFLICTS.md` | Data quality: gaps, report, coverage, numbers to review |
| `plans/` | Smaller plans (demo to real site, danger message, search, coverage fix, nationwide) |
| `reports/` | OpenStreetMap coverage reports |
| `security/` | Security audit |
| `srs/` | Software Requirements Specification (PDF, Markdown, screenshots) |
| `design/` | Design drafts (`portal-v2.html` is the reference) |

Old test screenshots (Oct 2026) are not in the repository; they were archived outside it.
