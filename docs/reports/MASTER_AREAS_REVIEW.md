- **Modification notice:** Adapted by SafeConnect: the official tables were extracted into JSON with names, codes, parents and coordinates unchanged; the links between the 2020 and 2023 codes and to the national portal list were derived by tools/build_master_areas.py and are marked as derived. BBS, OCHA and HDX do not endorse SafeConnect or this adaptation.
- **No boundary polygons were downloaded or used.** The current HDX dataset (v03) has polygons for divisions, districts and upazila-level units only; unions are **points**. A 2020 BBS / OCHA ROAP union polygon set (5,160 units) exists only as a third-party copy (geoBoundaries: simplified file 12.5 MB, full file 341 MB, sizes read from headers only). Its HDX origin page returns 404 and its licence statements conflict (CC BY 3.0 IGO there, ODbL on another HDX entry), so it is **not used**. **Rule:** a result from these points is called the *nearest union centre*, never an exact union.
